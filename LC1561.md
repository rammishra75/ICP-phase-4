# 1561. Maximum Number of Coins You Can Get

```
class Solution {
    public int maxCoins(int[] piles) {
        int sum = 0;
        Arrays.sort(piles);
        int cnt = 0;
        int pair = piles.length / 3;
        int i = piles.length - 2;
        while(i >= 0){
            if(cnt == pair) break;
            sum += piles[i];
            cnt++;
            i -= 2;
        }
        return sum;
    }
}
```
