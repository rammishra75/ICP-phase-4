# Water Bottles II

```
class Solution {
    public int maxBottlesDrunk(int numBottles, int numExchange) {
        int drunk = numBottles;
        int isEmpty = numBottles;
        while(isEmpty >= numExchange){
            isEmpty -= numExchange;
            numExchange++;
            drunk++;
            isEmpty++; 
        }
        return drunk;
    }
}
```
