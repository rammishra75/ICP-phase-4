# Maximum Total Sum of K Selected Elements

```
class Solution {
    public long maxSum(int[] nums, int k, int mul) {
        Arrays.sort(nums);
        int n = nums.length;
        int i = n-1;
        long ans = 0;
        while(k > 0){
            if(mul >0){
                ans += (long)nums[i]*mul;
            }
            else ans += (long)nums[i];
            i--;
            k--;
            mul--;
        }
        return ans;
    }
}
```
